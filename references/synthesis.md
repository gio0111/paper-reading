# 综述与证据综合

先确定综述的目标和类型，随后选择评价标准。叙述综述、系统综述、范围综述和元分析不是质量排名；元分析是一种定量综合方法，不是所有综述的必需部件。

| 类型／目的 | 重点阅读 | 避免误判 |
|---|---|---|
| 叙述、理论、批判性综述 | 论题、文献取舍理由、概念组织、争议与反例、论证来源 | 不因未按系统检索流程就直接判为无效；若声称覆盖全部证据，仍需支持 |
| 系统综述 | 问题范围、检索源与策略、时间与语言、纳入排除、筛选、提取、适合纳入研究的质量／偏倚评估、综合方式 | 系统检索不自动等于证据强；纳入研究的局限会传递到结论 |
| 范围综述／证据图谱 | 范围与概念、检索及筛选、分类框架、证据分布和缺口 | 通常不以估计疗效为目的；没有合并效应或逐研究偏倚评估不自动构成致命缺陷 |
| 元分析 | 可合并性、效应量及方向、模型与假设、依赖性、异质性、敏感性和报告偏倚、估计不确定性 | 平均效应不能代替不同情境；不机械套用单一异质性阈值 |
| 定性证据综合 | 材料来源、原研究语境、提取到概念的转换、跨研究解释、反例 | 不把解释性综合当成投票统计，也不机械要求效应量 |

阅读链：问题范围 → 哪些研究进入／遗漏 → 如何评价与组织 → 怎样形成综合结论 → 结论适用边界。

检查综述是否把“没有找到研究”当作“现象不存在”，或把“研究数量多”当作“结论可靠”。查阅时点、数据库、语言和发表类型影响覆盖范围；“最新”或“全部”必须有相应依据。

笔记中区分三层：原研究报告了什么、综述作者如何综合、你的判断是什么。只读综述而未读原始研究时，引用写成“该综述转述／汇总”，不要声称核实了原始研究。

第三遍优先追一个会改变结论的关键来源或分歧，不需要为了读一篇综述重做完整系统检索。用户明确要求完整综述项目时，说明这是新增检索与综合任务，沿其范围执行。
