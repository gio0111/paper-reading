# 实证研究：从研究设计到证据边界

用于实验、观察、调查、质性与混合方法。只选与核心主张有关的问题。质性研究不是定量研究缺少数字的版本。

## 定量：实验、观察与调查

先确定作者要描述现象、估计关联、预测结果还是解释因果，再评价设计。

| 环节 | 核对什么 | 为什么影响结论 |
|---|---|---|
| 对象和抽样 | 纳入排除、招募、样本量依据、情境与时段 | 结果代表谁；哪些对象系统性缺失 |
| 概念与测量 | 操作定义、工具及其在该情境中的适用性 | 测量指标是否对应作者声称的概念 |
| 干预与比较 | 分配方式、对照、实施程度、共同干预；盲法等按情境判断 | 比较组的差异是否只来自研究因素 |
| 时间与机制 | 测量顺序、随访、潜在混杂与替代机制 | 相关或先后关系是否足以支持因果 |
| 数据处理 | 缺失、退出、排除、异常值处理 | 分析样本是否改变了问题与人群 |
| 分析 | 方法对应的问题、关键假设、模型选择、敏感性分析 | 假设失败时结论如何受影响 |
| 结果 | 效应方向和大小、单位、区间或其他不确定性、基准及不一致结果 | 显著性不等于效应重要，未显著也不等于不存在效应 |

不要把“有随机化”当作全部可靠性，也不要把“非实验”一律判为不能研究因果；判断识别策略、假设及证据是否充分。样本量大小须结合问题、变异与设计，不设跨学科统一门槛。

读图表先确认坐标、单位、分组、样本基数、误差含义、图注以及正文对应论断。计算或换算注明来自哪些数值；没有数据不补算效应和区间。

核心输出：研究问题 → 设计与测量 → 关键结果 → 推断条件 → 可支持的结论。

## 质性：访谈、田野、文本资料与案例

- 研究希望理解何种体验、实践、意义或过程？研究立场是否影响资料与解释？
- 场域和参与者为何这样选择？接触与取材过程排除了什么声音？
- 资料如何获得、记录、整理？在该方法传统下，资料充分性的理由是什么？
- 作者如何从材料形成编码、主题、叙事或解释？关键引文是否能看出这一过程？
- 是否处理反例、矛盾经验及其他解释？研究者位置或介入如何影响资料？
- 结论依赖哪些具体情境？转移到别处需要确认什么？

不要把随机抽样、统计代表性、编码者一致性、饱和度或三角验证设为所有质性传统的统一必选项。先判断作者的方法立场，再解释某项检查为什么相关或不适用。

核心输出：问题与情境 → 材料及其来源 → 解释形成过程 → 支持片段／反例 → 可迁移的条件。

## 案例与混合方法

案例研究先辨认它是说明机制、比较解释、呈现异常还是描述个案；单个案例可以支持存在性或反驳普遍命题，不自动证明普遍发生率。

混合方法分别追踪定量与质性主张，再检查二者在设计、分析或解释的哪个环节结合。若二者冲突，呈现冲突及作者如何处理；不能用“采用两种方法”替代整合证据。

## 边界记录

每个实质性质疑写成“观察到的依据 → 可能影响的结论 → 待核实信息”。不要仅因论文未报告某个理想步骤就判定其整个研究无效；先判断该缺口是否影响所作主张。
