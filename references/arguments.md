# 证明、理论与解释性论证

这类文献的支持可以是形式推导、概念区分、文本、史料、案例或规范理由。识别每个主张属于哪一种；一篇文章可同时包含形式结果与未经检验的现实解释。

## 数学、形式证明与形式模型

1. 明确对象、定义、量词、定义域、假设、命题与贡献：新定理、新证明、反例还是界限。
2. 重建“前提 → 引理／关键构造 → 推导 → 结论”，说明每个关键步骤用到哪个条件。
3. 检查隐藏假设、边界情形、存在性与唯一性、必要与充分、有限与渐近等区别；按论文实际问题选择。
4. 用适当实例检查理解，用反例检验过强推广；举例不能代替证明，数值实验不能自动证成一般命题。
5. 区分模型内部结论、模型对现实的解释、计算实现的行为；三者需要不同支持。

只验证部分推导时，明确未检查的引理或外部定理，不能宣称已验证整个证明。无能力完成某关键验证时，把推理依赖和待核实点写清。

输出：命题与条件 → 证明骨架 → 关键依赖 → 已核对部分 → 反例／适用域。无需样本量、统计显著性或实验对照表。

## 概念与理论文章

核对问题如何提出、核心概念怎样定义、与相邻概念如何区分；前提与结论之间有什么推理；理论解释了什么、遗漏什么；反例是否需要收缩命题；比较理论是否被公平呈现。

对经验性的主张追问经验支持，对逻辑主张检查推理，对价值判断辨明规范前提。尚未经验检验可限制现实解释，却不自动否定概念分析的价值。

## 人文解释、历史与文本研究

- 文本／史料来自哪里、什么版本与语境？材料的保存与选择可能让哪些声音缺席？
- 作者实际依赖哪些细节，怎样从细节走到解释？引文脱离上下文后是否仍支持该读法？
- 解释是否处理不合自身论点的段落、来源冲突、时间差异或其他合理读法？
- 历史论断是否区分当时材料、后世记述与今日解释？不要把今天的概念直接投射到过去。
- 结论是在解释特定文本、提出可用视角，还是推广为普遍事实？推广范围是否有充分支持？

评价解释的材料依据、连贯性、解释力与边界，不能要求唯一实验验证。允许多个有依据的解释并存；不要为制造“批判性”而把所有读法说成同样有理。

## 规范论证、法学论证与评论

分开描述性事实、价值前提、规范原则和行动建议。看价值冲突如何处理、推理是否一致、反例／极端案例是否改变结论。涉及法律材料时区分文本内部论证与现行效力；用户要求现实法律判断时需另行核实适用法域和时点。

评论／观点文章先说明它的论证与证据性质，不冒充原创实证研究。指南或专家共识的建议形成过程另见 artifacts-and-plans.md。
