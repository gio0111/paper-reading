# paper-reading

跨领域论文阅读与训练 Skill，基于“三遍阅读＋同步记录”。

## 阅读流程

1. 阅读前：明确目的，确认原文及材料范围。
2. 第一遍：速读，辨认问题、贡献和支持方式，决定阅读深度。
3. 第二遍：精读，核对研究或论证过程、核心证据、解释与适用边界。
4. 第三遍：关联已读文献，复述、内化并提出带条件的迁移建议。
5. 全程记录：重点、疑问、质疑、迁移想法与续读进度。

## 两种模式

- **陪练**：读者先尝试，AI再提供定位、反馈和下一步，不提前代答。
- **分析**：直接形成结构化阅读笔记，区分作者主张、原文支持与读者判断。

根据主张和支持方式适配实证研究、质性研究、综述、数学证明、理论与人文论证、算法与工程系统、数据集、研究计划等。混合贡献分别核对证据；材料不全时保留未知，不补造事实。

## 使用

将整个仓库文件夹以 `paper-reading` 为目录名安装到支持 Skills 的助手环境。Codex 的个人技能目录可使用 `~/.codex/skills/paper-reading`；目录中保留 `SKILL.md`、`agents/` 和 `references/` 的相对结构。已有安装时，先比较内容再更新。

附上论文文件、正文或链接，然后输入：

> 用 $paper-reading 带我读这篇论文，从第一遍开始，让我先回答。

或：

> 用 $paper-reading 直接分析这篇论文，整理完整阅读笔记。

## 文件

- [SKILL.md](SKILL.md)：入口、类型路由及三遍阅读流程。
- [references/](references/)：各类论文的检查重点、陪练节奏与笔记约定。
- [agents/openai.yaml](agents/openai.yaml)：显示名称和默认调用提示。

## 验证范围

已通过技能格式校验，并以9个自编代表性场景试读，包括训练首轮与续轮、数学证明、仅摘要、人文解释、混合贡献、范围综述、研究计划及质性研究。此验证不代表穷尽所有学科或替代专业领域判断。
